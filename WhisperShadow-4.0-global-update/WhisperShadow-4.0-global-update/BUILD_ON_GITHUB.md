# WhisperShadow 0.5.0 — build on GitHub

This project is configured for Minecraft Java 1.21.11, Fabric, and Java 21.

1. Upload the project files to the GitHub repository.
2. Open **Actions**.
3. Select **Build WhisperShadow**.
4. Press **Run workflow** (or wait for the workflow after a push).
5. Open the successful run.
6. Download the artifact **WhisperShadow-0.5.0**.
7. Put the `.jar` from the artifact into `.minecraft/mods`.

The build uses Gradle 9.2.1 because the current Loom setup requires Gradle 9.2+.
